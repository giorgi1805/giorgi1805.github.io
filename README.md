# giorgi1805.github.io

Статический сайт-портфолио для GitHub Pages.

## Публикация
1. Создайте репозиторий `giorgi1805.github.io`.
2. Загрузите в его корень все файлы из этой папки, включая `index.html`, `assets`, `notes` и `HS0.7-main.zip`.
3. В настройках репозитория откройте **Settings → Pages** и выберите публикацию из ветки `main` и папки `/ (root)`.

После публикации сайт будет доступен по адресу `https://giorgi1805.github.io/`.
